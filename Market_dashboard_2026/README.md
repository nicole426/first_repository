# Market Dashboard 2026

A market data dashboard for tracking and visualizing financial market trends in 2026.

## Features

- Real-time market data display
- Historical trend analysis
- Portfolio tracking
- Customizable watchlists
- Interactive charts and visualizations

## Project Structure

```
Market_dashboard_2026/
├── README.md
├── index.html       # Main dashboard page
├── css/
│   └── styles.css   # Dashboard styles
├── js/
│   └── app.js       # Dashboard application logic
└── data/
    └── sample.json  # Sample market data
```

## Getting Started

1. Clone the repository
2. Open `index.html` in your browser
3. Explore the dashboard with sample market data
